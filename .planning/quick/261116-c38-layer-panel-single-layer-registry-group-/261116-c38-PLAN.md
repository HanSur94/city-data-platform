## Planning-time observations (verified 2026-11-16, these drive two refinements of the design)

1. Poll intervals vs registry intervals (towns/aalen.yaml vs LAYER_METADATA_REGISTRY): GTFSConnector polls every 604800 s but the transit registry interval is 1800; UBAConnector polls every 3600 s but the airQuality interval is 300. Live endpoint right now: airQuality last_updated 3310 s ago. With the literal rule max(3 x registry interval, 10 min), transit would show "Veraltet" from 1.5 h after each weekly fetch until the next one, and air quality would flip to stale 45 minutes of every hour although both sources run exactly on schedule. Refinement R1: the interval used for the threshold is the larger of the registry interval and the slowest poll interval among the layer's ENABLED connectors in the town config. The pure function takes these poll intervals as an optional argument; without it the literal design rule applies (both behaviours unit-tested). A null registry interval still means never stale.
2. WMS-rendered layers that the backend registry links to a connector: road noise is drawn by NoiseWmsLayer (LUBW WMS) but the registry links it to LubwWfsConnector, which actually fetches protected-area polygons and has never run; solar potential is a LUBW WMS in InfrastructureLayer, its SolarPotentialConnector is `enabled: false`; demographics is the Zensus WMS in DemographicsGridLayer. Their connector status does not describe what the map shows, so road noise and solar potential would show a false "Keine Daten". Refinement R2: registry entries for map layers drawn straight from an external WMS carry `externalWms: true`, and the sidebar passes no status for them (consistent with "WMS overlays get no status in this task"). Their data-type badge and info popover stay.
3. useUrlState.ts line 40 falls back to the default set `transit,aqi,buildings3d,terrain3d` when the `layers` param is ABSENT; today toggleLayer writes null for an empty list, which deletes the param and brings the defaults back. Group/master "off" makes an empty list likely, so the new URL writer writes an empty string (param present, empty) instead of null.
4. Toggle element ids (e.g. aqi-toggle) are referenced nowhere outside Sidebar.tsx (git grep), so ids may be regenerated from the registry.
5. The frontend metadata table keeps two legitimate source URLs on the mobidata-bw.de domain (transit sourceUrl, evCharging licenseUrl); the "removed layer" grep gate therefore excludes that domain.
6. Lint baseline of the files this plan touches (eslint JSON at HEAD): app/page.tsx 1 warning (no-unused-vars useMemo); components/map/MapView.tsx 1 warning no-unused-vars on the dead prop, 1 error react-hooks/immutability, 1 warning react-hooks/exhaustive-deps, 1 error no-explicit-any; components/sidebar/LayerToggle.tsx 1 warning no-unused-vars layerKey; all other touched files 0.

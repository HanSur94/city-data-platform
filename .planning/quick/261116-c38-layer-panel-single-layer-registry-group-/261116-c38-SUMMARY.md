One-liner: a single frontend layer registry (31 layers, 7 groups) now drives page state and URL writes, the sidebar gained tri-state group and master switches, and the backend reports a unit-tested per-layer connector status that the sidebar renders as "Keine Daten" / "Veraltet".

## What changed

- Backend: `compute_layer_status` and `newest_fetch` pure functions in `backend/app/routers/metadata.py`; `LayerMetadataItem.status` (`ok | stale | never_fetched | static`). Threshold is `max(3 x effective interval, 600 s)`, stale only when strictly older. Existing response fields, SQL and the registry (including the backend `mobiData` entry) are untouched.
- Frontend data path: `fetchLayerMetadata` is typed as `{ town, layers[] }`; `useLayerMetadata` now reads `layers` by `layer_key` (the old code misread the response shape, so metadata never reached the UI). Unknown or missing status yields `undefined` (no false "Keine Daten" against an old backend image). Client-side staleness computation removed.
- `frontend/lib/layer-registry.ts`: registry, groups, `visibilityFromUrl`, `nextUrlLayers` (drops unknown keys such as the removed one, de-duplicates), tri-state helpers.
- `page.tsx`: `layerVisibility = visibilityFromUrl(state.layers)`; `setLayers` performs exactly one `update({ layers })`; the two hand-written 32-line structures are gone.
- Sidebar: master row "Alle Ebenen" (27 data layers) plus seven group headers (Umwelt, Verkehr, Energie, Gemeinwesen, Infrastruktur, Karte & Overlays, 3D) with `n / m`, `aria-checked="mixed"` in the mixed state and a "k ohne Daten" hint. Toggle ids are now `layer-<key>`.
- Removed: the dead MobiData BW switch, its MapView prop and its frontend metadata entry; the four redundant `*Visible` Sidebar props.

## Planner refinements applied

- R1: poll interval of the town's enabled connectors raises the staleness threshold (GTFS 604800 s vs registry 1800 s; UBA 3600 s vs 300 s). Unit-tested both with and without `poll_intervals`.
- R2: road noise, solar potential, demographics, flood hazard, rail noise and cadastre are marked `externalWms` and show no status (badge and popover stay).
